# 🚀 Creative GSAP Animated Website

A premium, professional animated website built with **HTML5, CSS3, JavaScript, and GSAP 3**. Fully responsive, ready to deploy on GitHub Pages.

## ✨ Features
- Beautiful preloader animation
- Hero section with staggered text reveal & floating elements
- Rotating shapes & gradient glow effects
- Scroll-triggered animations for every section
- Smooth card hover & scale effects
- Fully responsive design (mobile, tablet, desktop)
- Modern dark theme with gradient accents
- Clean, organized code structure — easy to customize
